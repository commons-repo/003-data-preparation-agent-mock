Data Preparation Agent (Mock Version)

Zero-Configuration Sandbox

This page hosts the Mock Version of the Agentic AI Data Preparation Toolkit. It is designed specifically to facilitate peer review, allowing users to test the local data processing tools (parsing, subsetting, batching, and visualization) without requiring a paid OpenAI API key.

This mock environment mimics the actual agentic behavior reported in our work. Instead of querying a live Large Language Model, this interface uses keyword recognition to route specific user prompts to the authentic underlying Python tools, providing a precise simulation of the agent's workflow.

Download Mock Toolkit (ZIP, ~950 MB)

Data Management

The mock_data and temp_processing folders tackle all local data management. Input files are read directly from the mock data directories, while all processed files and generated visualizations are dynamically saved to the temporary processing folders so you can inspect the real outputs.

Installation & Launch

This environment is designed to run locally with zero configuration, provided the strictly verified Python environment is present.

*** CRITICAL PREREQUISITE ***
For strict scientific reproducibility and to prevent library dependency errors, this toolkit is locked to specific micro-releases. You must have one of the following installed:
  • Python 3.12.6 (Windows 64-bit)
  • Python 3.12.10 (Windows 64-bit)
Note: The setup script will intentionally block newer (3.13+) or older (3.12.3) versions.

Important Python Installation Steps:

When running the Python installer, you MUST do the following for the setup scripts to work:

  1. On the very first screen, check the box at the bottom that says: "Add python.exe to PATH".
  2. On the final successful installation screen, click the option to: "Disable path length limit" (highly recommended for virtual environments).

Running the Toolkit:

Step 1: Extract the entire downloaded archive to a local folder on your machine.

Step 2: Double-click setup.bat. This will verify your Python installation, create an isolated virtual environment, and install the necessary mathematical and UI libraries.

Step 3: Once setup is complete, double-click run_agent.bat. This will launch the local web interface in your default browser.

Mock Prompts & Keyword Triggers

Because this version runs deterministically without a live LLM, it requires specific prompts to trigger the data-processing pipelines. You can copy and paste the following exact prompts into the chat interface to simulate the workflows reported in our manuscript.

Note: While slight variations in prompts are acceptable as long as the core keywords are maintained, using the exact provided prompts is recommended for the optimal simulation experience.

Case 1: Basic Preview

Keyword Trigger: "show me the content"

Show me the content of this file: D:\1-1B.txt

Case 2: Complex Parsing & Formatting

Keyword Triggers: "first three rows" AND "fourth column"

In this file: D:\1-1B.txt, I do not need the first three rows (metadata). Also, only need the first column and the fourth column. Comma decimal separator should also be corrected. Can you do this and show me the modified file?

Case 3: Batch Processing & Metadata Alteration

Keyword Trigger: "batch process"

Please extend current operations to batch process other files located here: D:\parse_in. Save the processed files to: D:\parse_out. Also, I want to rename the first column header as 'time [s]' and the fourth column header as 'Fz [N]' while doing this.

Case 4: Data Visualization

Keyword Trigger: "create a plot"

Great! Please create a plot for this file: D:\parse_out\1-1B_parsed_20260516-170750-444019.txt
