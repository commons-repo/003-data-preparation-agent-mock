Data Preparation Agent (MockLLM)

This archive contains the Mock Version of the Agentic AI Data Preparation Toolkit. It is designed specifically to facilitate data preparation tasks without requiring a paid Large Language Model (LLM). This mock environment mimics the agentic behavior reported in our work (https://doi.org/10.21203/rs.3.rs-8872511/v1). Instead of querying a live LLM, this interface uses keyword recognition to route specific user prompts to the authentic underlying Python tools, providing a simulation of the agent's workflow.

Download Data Preparation Agent (MockLLM) [ZIP]
After downloading the ZIP, please click Installation Guidelines to install this mock version, and test drive with Mock Prompts to simulate the agent's behaviors as reported in the work.

This environment is designed to run locally with zero configuration, provided the strictly verified Python environment is present.

Step 1: Install a Verified Python Version

You must have one of the following installed:

  • Python 3.12.6 (Windows 64-bit)
  • Python 3.12.10 (Windows 64-bit)

IMPORTANT INSTALLATION STEPS:
When the Python installer window opens, you must check the following boxes before clicking Install Now:

  1. Check "Use admin privileges when installing py.exe"
  2. Check "Add python.exe to PATH"
Warning
For strict scientific reproducibility and to prevent library dependency errors, this toolkit is locked to specific python micro-releases. The setup script will intentionally block newer (3.13+) or older (3.12.3) versions. Please make sure you have either one installed from the above.

Step 2: Extract the Archive

Extract the entire downloaded archive (ZIP) to a local folder on your machine.

Step 3: Run Setup

Open the extracted folder, locate, and double-click setup.bat. This will verify your Python installation, create an isolated virtual environment, and install the necessary mathematical and UI libraries.

Step 4: Launch the Agent

Once setup is complete, locate and double-click run_agent.bat within that same folder. A terminal window will open and display a local web address (typically http://127.0.0.1:7860). Open this link in your web browser to access the interface.

After successful installation, test drive with Mock Prompts to simulate the agent's behaviors as reported in the work.

This deterministic version runs without a live LLM, it uses keyword detection to trigger specific data-preparation pipelines. To test drive the system and experience the agent's behavior exactly as reported in our work, we highly recommend copy-pasting the 18 example prompts below from start to finish.

Data Management: Input files are read directly from the mock_data directory. Processed files and visualizations are dynamically saved to temp_processing and subfolders within mock_data.
Processing Note: Prompts involving batch processing, segmentation, and peak extraction (e.g., 2, 3, 7, 8, 12) are data-intensive. Please be patient and wait for the processing to finish (indicated by "..." in the chat).

Example Mock Prompts

Mock Prompt 1 (Basic Preview)

Show me the content of this file: mock_data/1-1B.txt

Mock Prompt 2 (Complex Parsing & Formatting)

In this file: mock_data/1-1B.txt, I do not need the first three rows (metadata). Also, only need the first column and the fourth column. Comma decimal separator should also be corrected. Can you do this and show me the modified file?

Mock Prompt 3 (Batch Processing & Metadata Alteration)

Please extend current operations to batch process other files located here: mock_data/parse_in. Save the processed files to: mock_data/parse_out. Also, I want to rename the first column header as 'time [s]' and the fourth column header as 'Fz [N]' while doing this.

Mock Prompt 4 (Data Visualization)

Great! Please create a plot for this file: mock_data/1-1B_parsed.txt

Mock Prompt 5 (Segmentation Guidance)

I need to segment this file into multiple parts. What are the ways?

Mock Prompt 6 (Threshold Segmentation Parameters)

I think "segmentation by threshold" will help. What information do I need to provide?

Mock Prompt 7 (Execute Threshold Segmentation)

Segment using Threshold = 10, Search Window = 6000, Start and End Padding both are zero (0). X-axis column is the first one (time [s]). Data column is the second one (Fz [N]).

Mock Prompt 8 (Batch Threshold Segmentation)

Great! Can we extend this segmentation process for batch-processing the other files present in the folder: mock_data/segment_in? The output location would be: mock_data/segment_out.

Mock Prompt 9 (Show Segment Content)

Show me the contents of the files for segment 1 and segment 40.

Mock Prompt 10 (Visualize Segments)

I need to see the plots of these files as well. Create plots for segment 1 and segment 40. The first column (time [s]) as X-axis and the second one (Fz [N]) as Y-axis.

Mock Prompt 11 (Peak Extraction Guidance)

From the plots, I see there are certain peaks in each. I need to perform such peak extraction. Any way?

Mock Prompt 12 (Peak Extraction Execution)

Thanks! For trial, let's perform peak extraction on this file: segment 1. Settings are: maxima, X Column: "time [s]", Y Column: "Fz [N]", prominence: 5, height: 10, and distance: 50.

Mock Prompt 13 (Batch Peak Extraction)

Great! Can we extend this peak extraction for batch-processing the files I have here: mock_data/peak_in? I want the output files saved in this folder: mock_data/peak_out. Settings are: maxima, X Column: "time [s]", Y Column: "Fz [N]", prominence: 5, height: 10, and distance: 50.

Mock Prompt 14 (Show Peak File Content)

Show me the contents of this file: mock_data/1-1B_parsed_segment_1_peaks.txt.

Mock Prompt 15 (File Modification Guidance)

I see I need to delete some columns, add a new column, and add some metadata on top. Can we do that?

Mock Prompt 16 (File Modification Execution)

Modify the file: mock_data/1-1B_parsed_segment_1_peaks.txt. Columns to delete: 1st, 2nd, and 4th. Add a new column with header 'i'. Start with 1, with Step increase '1'. This 'i' column should be the first column. Metadata: Process: Micro Drilling, Tool: Solid Carbide micro-INOX 8×D drill, Workpiece: Titanium Block (Ti6Al4V), Cycle: 1.

Mock Prompt 17 (Batch File Modification Guidance)

Is there any way to extend this batch modification to all the files in the folder: mock_data/modify_in? I need to delete some columns and add metadata.

Mock Prompt 18 (Batch File Modification Execution)

Perform batch modification for all files in mock_data/modify_in. Columns to delete: 1st, 2nd, and 4th. Add a new column with header 'i'. Start with 1, with Step increase '1'. This 'i' column should be the first column. Metadata: Process: Micro Drilling, Tool: Solid Carbide micro-INOX 8×D drill, Workpiece: Titanium Block (Ti6Al4V), Cycle: 1. Save all modified files in mock_data/modify_out.

Technical Reference: Keyword Routing Details

For debugging or prompt variation, these are the exact keyword rules the system uses to route requests.

  • Mock Prompt 1: "show me the content" AND NOT "segment"
  • Mock Prompt 2: "first three rows" AND "fourth column"
  • Mock Prompt 3: "batch process"
  • Mock Prompt 4: "create a plot" AND NOT "segment"
  • Mock Prompt 5: "segment" AND ("ways" OR "methods" OR "how") AND NO numbers
  • Mock Prompt 6: "segment" AND "threshold" AND ("what information" OR "what parameters" OR "what do I need" OR "what do you need") AND NO numbers
  • Mock Prompt 7: "segment" AND "threshold" AND "="
  • Mock Prompt 8: "batch" AND "segment"
  • Mock Prompt 9: "show" AND "content" AND "segment" AND numbers AND NOT "peak"
  • Mock Prompt 10: ("plot" OR "visualize") AND "segment" AND numbers
  • Mock Prompt 11: "peak" AND ("extract" OR "extraction" OR "detect" OR "detection" OR "find") AND NO numbers
  • Mock Prompt 12: "peak" AND ("perform" OR "extract" OR "extraction" OR "execute" OR "detection" OR "find") AND numbers AND NOT "batch"
  • Mock Prompt 13: "batch" AND "peak"
  • Mock Prompt 14: "show" AND "content" AND "peak"
  • Mock Prompt 15: ("delete" OR "add" OR "modify") AND ("column" OR "columns") AND ("how" OR "way" OR "ways" OR "method" OR "methods" OR "what" OR "can we" OR "can I") AND NOT ("threshold" OR "maxima" OR "minima" OR "width" OR "distance" OR "prominence" OR "height")
  • Mock Prompt 16: ("delete" OR "add" OR "modify") AND ("column" OR "columns") AND actual parameters provided AND NOT ("threshold" OR "maxima" OR "minima" OR "width" OR "distance" OR "prominence" OR "height")
  • Mock Prompt 17: "batch" AND "modification" AND ("delete" OR "add" OR "modify") AND ("how" OR "way" OR "ways" OR "method" OR "methods" OR "what" OR "can we" OR "can I" OR "is there" OR "any way")
  • Mock Prompt 18: "batch" AND "modification" AND ("delete" OR "add" OR "modify") AND actual parameters provided
