# Data Preparation Agent (MockLLM)

This repository contains the Mock Version (Zero-Configuration Environment) for test-driving the agentic toolkit developed and described in our research work: *Systematizing Data Preparation in Smart Manufacturing via Axiomatic Design: A Toolkit Integrating GUI and Agentic AI* (DOI: [10.21203/rs.3.rs-8872511/v1](https://doi.org/10.21203/rs.3.rs-8872511/v1)).

To download the standalone toolkit archive (ZIP), read the installation guidelines, and view the mock prompts, please visit this [Download Portal](https://commons-repo.github.io/003-data-preparation-agent-mock/).
